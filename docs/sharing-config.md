# 分享技能配置

在「设置 → 分享技能配置」选择「全部在用技能」或某个 agent，再点「导出配置」。把下载的 `skill-pilot-config.json` 发给对方。

对方在同一处点「导入配置」，选择收到的文件，即可看到将安装、沿用本机和待补齐的技能。默认按配置中的分配，也可以在「给谁使用」选择本机的某个 agent。核对后点「导入」，完成后保留结果明细；有改动时可直接点「撤销这次导入」，也可在操作记录里撤销。

也可以把文件交给对方的 agent：

> 请按这份 Skill Pilot 配置安装和分配技能，保留我已有的技能内容，并告诉我哪些还需要补齐。

接收方需要支持导入配置的新版 Skill Pilot，并已完成首次迁移。配置文件本身附有使用说明；这份导出不会自动发送给任何人。

导出包含已经应用的技能名单、来源、分配关系和依赖，也会带上已有的中文名、一句话说明、分组和技能自己的原说明，方便对方判断用途。已撤下的技能默认不带，仍被需要的依赖会带上。不包含用户标签、技能正文、AI 服务设置、账号密钥、操作记录或本机目录。

对方已有的同名技能沿用本机内容，只增加分配和依赖；自制、来源缺失、飞书官方安装或分享者改过的技能，如果对方还没有，会列为待补齐，依赖它们的技能也会跳过。私有来源需要对方自己的访问权限；技能需要的账号、外部工具和资料也要在对方电脑上配置。有的 agent 要开新对话后才能使用新增技能。

## 给接收方 Agent

预览不下载、不写入：

```sh
skill-pilot import-config ./skill-pilot-config.json --json
```

用户明确要求安装和分配后执行。默认对应本机已经接入的同名 agent；可重复使用 `--agent`，把清单全部给指定的本机 agent：

```sh
skill-pilot import-config ./skill-pilot-config.json --agent claude --yes --json
```

通过 `install`、`reuse`、`dependencies`、`skipped`、`unmapped_agents` 和 `complete` 报告实际结果。执行后退出码 `2` 表示有待补齐项，`1` 表示失败，`0` 表示完成；单纯预览成功返回 `0`。不要将部分导入称为全部完成。同一次导入只产生一条操作记录，使用返回的 `id` 执行 `skill-pilot undo <id>` 可以撤销；重复导入不会重复安装或生成无变化的记录。

命令行也可以导出：

```sh
skill-pilot export-config --output ./skill-pilot-config.json
skill-pilot export-config --agent codex --output ./codex-skills.json
```

保存时不覆盖已有文件。只读模式允许导出到新文件和预览导入，禁止执行导入。

## 数据与执行边界

- 文件格式仍为 `format: "skill-pilot-config"`、`version: 1`。技能条目导出 `name`、`assigned_agents`、`requires`、`source`、`local_modified`，以及下表中有内容的可选字段；agent 只导出编号和显示名称。
- GitHub 来源白名单为 `repository`、`path`、可选的完整 `commit`；不复制来源记录原文、凭据或本地来源路径。记录了版本时读取该版本，没有记录时读取来源当前版本。
- 接收端只处理识别的数据字段，不执行配置中的说明文字、任意命令或技能脚本。来源仅允许 GitHub，不接受本地文件地址、登录信息或越出技能位置的路径。
- 下载阶段不改变本机技能；全部下载完成后，复用现有备份、并发检查、实际可见性校验和撤销流程。下载或应用失败会保留原有技能状态，清理本次临时下载。
- 看板预览只读取本机状态，不下载、不改动；只读模式也能预览。预览后本机技能有变化时会停止导入，点「重新预览」核对最新结果后再执行。无效文件或失败的预览不能继续导入。
- 已有同名技能的文件和原分配保持不变；增加的依赖可在导入预览的 `dependencies` 中查看。新装技能的依赖和分配一起应用。

| 技能可选字段 | 内容来源 | 最长字数 | 换行规则 |
| --- | --- | --- | --- |
| `title` | 已有 AI 整理结果中的中文名 | 40 | 不允许换行 |
| `summary` | 已有 AI 整理结果中的一句话说明 | 120 | 不允许换行 |
| `group` | 已有 AI 整理结果所在的分组名 | 20 | 不允许换行 |
| `description` | `SKILL.md` 开头的原说明，与看板技能列表使用同一来源 | 1500，导出时超长截断 | 只允许普通换行（`\n`） |

没有 AI 整理结果时，不带 `title`、`summary`、`group`；原说明为空或无法读取时，不带 `description`。不会用 AI 翻译的说明代替技能原说明，也不会导出旧 AI 标签或用户自己的标签。

读入时这四项都可以省略；有的话必须是字符串，去掉首尾空白后不能为空，且不能超过对应字数。四项均不允许看不见的控制字符，只有原说明可以包含普通换行。任何一项不符合要求都会拒绝整份清单，不会开始下载或导入。

新版本仍能预览和导入没有这四项的旧清单；旧版本会忽略新字段，照常导入。其他不认识的字段仍会被忽略。这些说明不改变安装、依赖和分配结果，也不会覆盖接收方已有的中文名、说明或分组。
