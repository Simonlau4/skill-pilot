## 1. 目标

用户原话：“现在前端做的太烂了，看不下去。”用户不是程序员，看板是用户管理四个助手（Codex、Claude、Antigravity、DSH）技能的唯一界面。重做后要做到：

1. 打开就知道每个助手有几个技能、占多少说明字数，能直接勾选分配；
2. 页面少、每页只干一件事，开发期诊断页面退到不显眼的位置；
3. 每个按钮按下后都有一致的反馈：正在做 → 做完了（能撤销的给撤销） → 出错了（大白话 + 重试）；
4. 看起来像一个安静、干净、可靠的本机工具，不像网页模板。

现有功能一个都不能丢，只能挪位置或合并（§3 有对照表）。

## 2. 技术约束（已定，不要再讨论）

- **不引入框架、构建工具、npm 包、CDN、外部字体或图片。** CSP 本来就是 `default-src 'self'`，外部资源会被拦。
- 最终只有三个前端文件：
  - `skill_pilot/web/static/index.html`：页面骨架，不再含 `<style>` 块，不用 `style="..."` 属性；
  - `skill_pilot/web/static/app.css`（新增）：全部样式，开头用 CSS 变量定义颜色、间距、圆角、字号；
  - `skill_pilot/web/static/app.js`：全部逻辑。按“通用工具（请求、转义、提示、确认框、按钮忙碌态）→ 各页面”分段，每段加一行中文注释说明是哪页。正常换行缩进，不要再写一行上千字符的代码。
- 只用原生 DOM 和 `fetch`；所有插入页面的文本都经过 `escape()`（沿用现有函数）。
- 不用 `window.confirm` / `window.alert` / `window.prompt`。确认统一用一个 `<dialog>`。
- 浏览器只需支持用户本机的新版 Chrome / Safari。桌面优先，宽度 ≥ 1024px 体验完整；窄到 800px 时表格可横向滚动，第一列固定。
- 不做深色模式、不做多语言。
- 现有测试 `tests/test_m5_web.py` 断言 `index.html` 不含“依赖建议”、`app.js` 不含 `data-dependency=`，保持成立。

## 4. 页面要求

### 4.0 页头（所有页共用）

- 左：产品名 “Skill Pilot”，一行副标题即可，不要现在 38px 的大标题。
- 四个助手的摘要条，顺序固定为 Codex、Claude、Antigravity、DSH（现在首页和勾选表顺序不一致，统一）：`名称 · N 个技能 · 说明 X 字`；有待应用改动时显示 `→ 应用后 M 个 / Y 字`，变化的数字用强调色。现在首页四张大卡片和勾选表四张卡片重复，删掉重复，只保留这一处。
- 每个助手的“生效方式”（Claude、DSH 马上生效；Codex、Antigravity 新会话生效）不要再挤进表头，放在摘要条上做一行小字或悬停说明。
- 后台任务条：用量统计、检查更新在后台跑时，页头下方出现一条细的进度条，写清楚“正在统计用量（第 3/12 个会话）”这类大白话，完成后自动消失；出错就变成警告样式并给“重试”。现在分散在 `updates-progress`、`usage-progress` 两处，合并到这里。
- 看板断开（心跳失败）时，页头显示一条醒目的提示：“看板已关闭或连接中断。重新双击 Skill Pilot 即可继续。”

### 4.1 技能页

- 工具条：搜索框（名称和说明）；筛选：全部 / 没分配给任何助手 / 很久没用 / 你改过 / 有依赖；右侧按钮“安装技能”（主按钮）和“重新盘点”（次要）。
- 发现未收编的新技能时，在工具条上方出一条横幅：“发现 3 个新技能还没收进仓库” + “一键收编” + “看看是哪些”（展开列表）。
- 表格：一行一个技能，列为 `技能 | Codex | Claude | Antigravity | DSH | 最近使用 | 说明字数`。
  - 表头和第一列固定（sticky），130 行时滚动不迷路。
  - “技能”列：名称加粗 + 说明一行截断（悬停或展开看全文）+ 小标签（你改过、有依赖、来源）。不要再在这里写多行来源说明。
  - 助手列只有勾选框，居中。Codex 与 DSH 共用目录的联动规则沿用现有逻辑，联动时在勾选框旁给一句小字说明，不弹窗。
  - “最近使用”只占一行：取各助手里最近的一次，写“3 天前”“60 天没用”“统计不到”；每个助手各自的情况放进详情面板。现在每行四行“最近使用”是表格太长的主因。
  - 数字列右对齐、等宽数字（`font-variant-numeric: tabular-nums`）。
- 点击行（勾选框以外的地方）打开右侧详情面板（不是弹窗），内容：完整说明、来源、存放位置、各助手最近使用和近 30 天次数、依赖（沿用现有的手动加减依赖功能）、是否本机改过。原“技能清单”页里按目录列出的信息（链接是否失效、是否 Codex 只允许手动调用、是否被停用）放在这里。
- 原“技能清单”的“同时看内置和插件”和“按目录筛选”：放进“诊断与备份”页，主表只管用户技能。
- 原“用量”页的数据并入表格和详情面板；“更新用量”变成后台任务（页头任务条），覆盖说明（如“Claude 的记录只保留最近 30 天”“Antigravity 暂时统计不到”）放在表格下方一行小字。
- 待应用改动：勾选后不立即写入。屏幕底部固定一条操作栏，仅在有改动时出现：“将给 Claude 加 2 个、从 Antigravity 撤下 1 个”，下一行写依赖带来的自动改动；按钮“应用”（主）、“取消”（次）。应用 → 确认框（列出明细）→ 按钮忙碌态 → 成功提示（带“撤销”）→ 刷新表格和页头数字。
- 安装技能：保留现在的流程（粘贴链接 → 读取仓库 → 勾选技能 → 选助手 → 安装），用右侧面板或对话框都行，但要和全站风格一致。同名冲突对比（`incoming-conflicts`）照旧可用。

### 4.2 检查更新页

- 页面中间一个主按钮“检查更新”，下面一句说明“只检查，不会自动安装”。
- 检查过程中逐条出结果（沿用现有逐条进度接口），已查/总数显示在页头任务条。
- 结果列表每条一行卡片：勾选框（默认选中）、技能名、来源、变化摘要；本机改过的显示“你改过”标签和二选一（默认“用上游的”，可改“保留我的”）；“交给 Codex 合并”“让 Codex 解释”是文字链接样式的次要操作，不是默认流程。脚本风险提示（新增/改动可执行文件、命中联网/删除/安装等关键词）用琥珀色块标出命中的文件和那一行原文。
- 底部固定操作栏：“更新选中的 N 个” + “全部更新”。完成后提示可在操作记录撤销。
- “其他技能”（无更新、查不到来源等）折叠在最下方。

### 4.3 清理页

- 顶部一行：各助手清理后能省多少说明字数。
- 名单默认全选，用户只取消要留的；说明沿用“取消勾选要留的，视为今天用过，60 天后才会再出现。清理只从助手撤下，文件留在仓库”。
- 应用 → 确认框 → 忙碌态 → 成功提示（带撤销）。
- 下半部分“已撤下的技能”：列表 + 每条“恢复” + “检查已撤下技能的更新”。

### 4.4 操作记录页

- 时间线：时间、做了什么（大白话一句）、影响了哪些技能（可展开）、“撤销”按钮。撤销同样走确认框。

## 5. 视觉规范

参考两份本机技能，**直接读文件，不要通过技能管理改分配**：

- `~/.skill-pilot/store/redesign-existing-projects/SKILL.md`：按它的“扫描 → 诊断 → 修复”顺序做，先对现有页面列出问题清单（写进报告），再改。重点用它的 Typography、Interactivity and States、Content、Code Quality 几节和 Fix Priority。
- `~/.skill-pilot/store/minimalist-ui/SKILL.md`：用它的色板和组件规则（暖白底、1px 浅边框、灰阶文字、单一深色主按钮、低饱和状态色、几乎不用阴影、不用渐变和表情符号）。

这两份是给营销网站写的，下面这些**不要照做**：外部字体（Geist、Newsreader 等）、图标库（Phosphor、Lucide 等）、picsum 之类的占位图、背景图片、噪点纹理、玻璃效果、滚动入场动画、错位叠放布局、衬线大标题。这是本机工具，要克制。

具体取值（可微调，但要统一用变量）：

- 字体：`-apple-system, BlinkMacSystemFont, "PingFang SC", "Helvetica Neue", sans-serif`；路径和代码用 `"SF Mono", Menlo, monospace`；正文 14–15px，页面标题 20–22px，字重用 400/500/600。
- 颜色：底色 `#F7F6F3`，面板 `#FFFFFF`，边框 `#E8E6E1`，正文 `#2F3437`，次要文字 `#787774`，主按钮 `#2F3437` 白字，强调色（勾选、焦点、链接、变化的数字）保留现有绿 `#2F6B4F` 一种。状态色：成功 `#EDF3EC`/`#346538`，提醒 `#FBF3DB`/`#956400`，危险 `#FDEBEC`/`#9F2F2D`，信息 `#E1F3FE`/`#1F6C9F`。
- 圆角：控件 6px，面板 10px。阴影只给对话框和右侧面板，且很淡。
- 间距用 4/8/12/16/24/32 一套。
- 动效：悬停、按下、面板滑入 150–200ms，只动 `transform` 和 `opacity`。
- 所有可点元素有悬停、按下、键盘焦点样式；勾选框和按钮点击区域不小于 32px。
- 空状态写一句有用的话（如“没有需要清理的技能。60 天内都用过。”），不要留空白。

文案：大白话中文，不出现 symlink、diff、git、TOML、hash、API、JSON 这类词；成功提示不用感叹号；报错写清楚发生了什么、用户能做什么。现有文案里好的句子直接沿用。

   ```sh
   PY=~/.local/share/uv/python/cpython-3.11-macos-aarch64-none/bin/python3.11
   FAKE=$($PY -c "import tempfile;print(tempfile.mkdtemp(prefix='sp-dsh-'))")
   ```
