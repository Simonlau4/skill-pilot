# Skill Pilot 当前状态

更新：2026-10-19。新对话先读这一页。

项目最高准则：[通用化与可复现](../AGENTS.md#最高准则通用化与可复现)（2026-10-15 用户确认）。本页既有的维护者本机验收记录，不能代替其他用户按公开步骤安装和使用的验证。

当前生效方式：“设置 → 版本”支持检查、下载和升级程序；首次安装接入这一版后，普通升级可全程在看板完成，刷新浏览器生效，正在执行的操作会先完成。尚未支持刷新切换的旧看板首次升级时仍需正常重开一次；下文早期记录中的“关掉后重开”是当时的处理方式。

公开版本验收发现的 ZIP 清单修复（2026-10-15，PR #16 已并入默认版本 main，97b80b8）：主体功能已进入 `main`，随后从 GitHub 实际下载的 ZIP 复现“最新版仍提示有更新，升级时同名文件冲突”。原因是安装清单漏记根目录的 `skill-pilot` 启动文件。修复已将其纳入清单，测试夹具也补上真实启动文件；17 项升级专项和 261 项全量检查通过，公开下载包按修复后的清单逻辑验证通过。本次通过独立分支和 PR 交付，不直接推送 `main`。源码安装不受此问题影响；已装首版 ZIP 的用户在修复合并后，需要手动获取修复版、重新运行一次安装命令重建清单，步骤见 [README.md](../README.md#更新程序)。

安装摘要直接显示技能名（2026-10-17，#64，PR #68 已并入；来自 #62，UX-02）：粘贴链接并读完后，左边的摘要卡片直接写技能名、一句话用途，以及装给当前正在看的 agent。读到多个时先列出前三个，可以查看全部。点一下就装，不增加确认；装完可以撤销。「挑一挑」窗口的用法没有改。

技能详情的键盘焦点（2026-10-17，#65，PR #67 已并入；来自 #62，UX-03）：详情打开时，Tab 和 Shift+Tab 只在详情里的控件之间循环，后面的页面不会被点到，也不会跟着翻页。Esc 仍能关闭，关闭后焦点回到打开这个详情的技能。详情里的内容和样子没有改。

看板打开时自动检查一次新版，有新版就在技能页提醒（2026-10-16，#37，PR #38 与 PR #54 已并入）：同一次运行里不重复查；只读时不查；自动检查失败时不弹红色报错，设置里只显示还没查到新版信息。有新版时，设置页可以直接升级，不用先点「检查更新」；技能页左栏最上面出现「SP 有新版」和「升级」，两边用同一份进度。打开看板时的这次自动检查不在页头显示进度。已是最新、还没查到、正在检查、只读时不显示左栏这张卡片。关掉看板或刷新应用新版时，不再干等这次自动检查（#39，PR #43）；手动检查和升级仍会等它做完。

安装改到技能页左栏（2026-10-16，#36，PR #52 已并入）：工具栏上的「安装」拿掉了。左栏可以粘贴链接，后台读取时页面照常能切换、勾选和检查更新。读完先给一张概要，可以一次装给当前正在看的 agent，也可以打开原来的窗口挑。2026-10-17 起这张概要直接写技能名和一句话用途（见上，#64）。

页头只留技能、清理、设置（2026-10-16，#35，PR #40 已并入）：操作记录、诊断与备份改在设置页里，功能还在；以前的地址会打开设置里对应的一块。设置页左边是目录，右边依次是 AI 整理、agent、分享配置、操作记录、诊断与备份、版本。「SP 自身更新」改叫「版本」，「额外技能源」在界面上改叫「其他技能文件夹」。还没整理过的新用户打开技能页就是首次整理。还没整理过、又是只读时，右上角也会显示「只读预览」（#41，PR #44）。

还没整理过就打开清理页（2026-10-16，#42，PR #45 已并入）：不再弹出红色报错，列表也不再停在「正在读取…」。页面说明要先做首次整理，并给出到技能页的入口。给用户看的「迁移」说法改成「整理」。

按文件夹接入一个 agent（2026-10-16，#1，PR #23 已并入）：设置页可以填写名字和技能文件夹，命令行也可以。先预览，确认后才写入，可以撤销。
