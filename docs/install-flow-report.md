# 安装流程后端改动报告

2026-10-14。已按 `docs/handoff-install-flow.md` 完成两处后端改动，197 项全量测试通过。目标仓库本次读取用时 7.064 秒；交接记录中的旧耗时为 71.6 秒。

## 改了什么

`skill_pilot/sources/github.py`：

- 安装预览改用 `clone --depth 1 --no-local --filter=blob:none --no-checkout`，先读取文件清单，再取技能所在文件夹。
- 分支和标签继续用 `--branch`；指定提交继续先 `fetch --depth 1 origin <提交>`，文件清单与检出都使用该提交。
- 用 `ls-tree -r -z --name-only` 查找文件名恰好为 `SKILL.md` 的文件，按父文件夹设置 cone 模式的 sparse checkout。不存在的子路径保留原报错，没有技能时返回空列表；技能在仓库根目录时完整检出。
- 文件夹通过标准输入传入，并处理引号、中文、空格和开头的短横线；保留以空字符分隔的文件名，不会误去掉开头空格。
- 后续扫描、名称检查、同名检查、外部链接检查、内容摘要及来源字段沿用原逻辑。钩子等保护保持原样，不执行仓库中的程序。

`skill_pilot/labels.py`：

- 每批最多 5 个技能，原始说明合计最多 3000 字；单条原始说明超过 3000 字时单独成批，实际发送仍截到 1500 字。
- 完全没有显示资料的技能优先，其次补齐已有中文名但缺说明或标签的技能；同一优先级按名称排序。
- 每批前重新读取登记表，把本轮尚未列入、也没有显示资料的新技能放到队首，并增加进度总数。最后一批运行期间装入的新技能也会被接着处理。
- 已有中文名、简述和分组继续保留，只补说明和标签；每批完成就保存，保存时按最新登记表剔除已移除的技能。服务报错之外的内部错误继续使用通用提示。
