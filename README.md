# Skill Pilot · 本机 Agent 技能管理

统一管理本机多个 Agent 的技能，解决四个常见问题：

- **不用各管各的**：内置 Codex、Claude、Antigravity、DSH、Cursor、豆包工作和 WorkBuddy 的接入规则，也可在看板接入电脑上发现的其他 Agent。
- **同一技能不再多份副本冲突**：每个技能只存一份正本，自由决定给哪个 Agent 启用，前置依赖自动一并带上。
- **更新不用专门开对话**：在看板点一下「检查更新」，有新版的技能可单独更新或全部更新。
- **看清上下文占用**：直观显示每个 Agent 启用了多少技能、单次对话预占约多少 Token，不常用的随时撤下。

Token 是衡量文本长度的单位；看板按技能说明的长度估算，用来比较单次对话的上下文占用。

## 怎么用

- **打开看板**：
  - **macOS**：双击 `~/Applications/Skill Pilot.app`（或 Spotlight 搜索 `Skill Pilot`）。
  - **Windows**：从开始菜单打开 **Skill Pilot**。
  - 关闭所有看板页面后，后台程序会自动退出。
- **在对话里调用**：首次整理后，打开看板会给已接入的 Agent 安装 `skill-pilot` 技能，平时在对话里可直接说“看看 Claude 有哪些技能”“把 X 也给 Antigravity 启用”。
- **命令行**：`skill-pilot status`、`skill-pilot list --agent claude`、`skill-pilot check-updates`、`skill-pilot cleanup --list`，加 `--json` 输出结构化结果。

看板里的主要模块：

| 页面 | 做什么 |
| --- | --- |
| **首页** | 查看技能库总览与技能分布星图、各 Agent 状态（启用技能数与单次对话预占约多少 Token）、待处理事项和近期改动记录，点一下前往对应页面；首次使用按提示前往技能页完成首次整理 |
| **技能** | 选择给哪个 Agent 启用或撤下技能（前置依赖自动一并带上，核对后应用更改）；左栏粘贴 GitHub 技能链接直接安装；按分组、个人标签搜索筛选 |
| **技能 → 首次整理** | 第一次使用时，把各 Agent 现有的技能收进同一份技能库（整理前先完整备份，随时可还原） |
| **技能 → 检查更新** | 按一下才查；可单独更新或全部更新；失败项列出原因，其他项继续；飞书技能整组更新 |
| **清理** | 对照单次对话预占的 Token，手动选择不需要的技能从各 Agent 撤下（本地文件保留，可在「已撤下的技能」里恢复） |
| **团队** | 连接团队分享站后出现：浏览同事上架的技能、推荐语与星级评价，点一下加入安装队列，等待时可继续浏览；安装完成后再分配给 Agent，也可上架自己的技能 |
| **设置 → AI 整理** | 填写 AI 服务的 API 密钥，自动为英文技能生成中文名、中文说明和分组 |
| **设置 → Agent** | 重新扫描 Agent、一键接入新发现的 Agent、停止管理；其他技能文件夹也在这里记录 |
| **设置 → 分享配置** | 导出在用技能、来源和分配关系；收到配置后先预览，再批量导入，支持整批撤销 |
| **设置 → 团队分享** | 填写局域网团队分享站地址（开放加入只填名字，限制加入时填管理员口令）并连接 |
| **设置 → 操作记录** | 默认收起，展开查看最近 10 次改动并撤销；完整历史记录可导出 |
| **设置 → 诊断与备份** | 排查版本差异、查看各目录清单、执行整理与还原 |
| **设置 → 版本** | 从官方 GitHub 项目检查并一键升级 Skill Pilot，更新启动入口，刷新后生效 |

## 安装

当前支持 **macOS** 和 **Windows** 本地桌面：

- **macOS**：需要 Python 3.11.4 或更高版本，以及可用的 Git；飞书技能更新另外需要 Node.js 和 npm。
- **Windows 10 / 11**：需要 Python 3.12 或更高版本、可用的 Git for Windows，并在系统设置中开启 Windows 开发者模式；Windows 不自动升级飞书 CLI。
- Python 最低版本用于支持下载文件的安全解包，见 [Python 官方说明](https://docs.python.org/3.11/library/tarfile.html#extraction-filters)；飞书工具的依赖与账号配置见 [飞书官方安装说明](https://github.com/larksuite/cli#installation--quick-start)。

### macOS 安装

从 GitHub 获取源码后，在项目文件夹运行（也可下载并解压 GitHub 的源码 ZIP，在解压出的项目文件夹运行最后一条命令）：

```bash
git clone https://github.com/Simonlau4/skill-pilot.git
cd skill-pilot
sh scripts/build-app.sh
```

安装器会识别当前用户可用的 Python 和工具位置，生成桌面应用 `~/Applications/Skill Pilot.app` 与命令行入口 `~/.local/bin/skill-pilot`（把 `~/.local/bin` 加入命令搜索路径后可直接用 `skill-pilot`）。用户名、项目位置和路径中的空格均可不同；若有多个 Python，可用 `SKILL_PILOT_PYTHON="/你的路径/python3" sh scripts/build-app.sh` 指定符合要求的版本。

双击当前用户 `Applications` 文件夹里的 **Skill Pilot.app** 打开看板，按页面提示选择要接入的 Agent、核对首次整理结果。项目文件夹需要保留；移动位置后，在新位置重新运行一次安装命令即可。

### Windows 安装

Windows 用户从 GitHub 获取或解压完整源码后，在项目文件夹运行：

```powershell
python -X utf8 -B scripts/install.py
```

随后从开始菜单打开 **Skill Pilot**。首次整理前需开启 Windows 开发者模式。完整安装与后续看板升级步骤见 [Windows 说明](WINDOWS.md)。

### Agent 识别与飞书工具补充说明

- **识别与接入新 Agent**：
  - Cursor、豆包工作和 WorkBuddy 会按已安装应用或各自的应用数据识别，还没装过用户技能也会显示。在 macOS 上，应用放在系统或当前用户的 `Applications` 文件夹时可直接识别；放在其他位置时，先正常打开一次该应用建立应用数据，再打开或刷新看板。内置技能、市场、插件和连接器只查看；豆包工作使用桌面应用数据中的用户技能目录。目录依据与验证范围见 [Agent 识别说明](docs/agent-discovery-report.md)。
  - 新装了 Agent 不用重启看板：在 **设置 → Agent** 点 **重新扫描 Agent**，会进一步查找主目录隐藏文件夹中的技能目录。
  - 首页提醒和设置里的已发现 Agent 都只需点一次「接入」，后台读取并显示进度；等待期间可继续浏览技能，失败可重试，完成后可撤销。同名技能默认沿用统一仓库里的版本；只有尚未收录、又存在多份不同内容的技能需要选一次版本。手动填写名字和文件夹时仍先显示预览。
- **飞书工具（macOS）**：
  - 已有飞书工具会自动识别（支持常见的用户安装目录、Homebrew 和 nvm 环境）。新用户先按官方说明安装并用自己的账号授权；若要将工具装在当前用户目录，可执行：
    ```bash
    npm install --global --prefix "$HOME/.local" @larksuite/cli
    export PATH="$HOME/.local/bin:$PATH"
    lark-cli --version
    ```
  - 在其他目录安装工具时，先让命令在终端可用，再运行一次 Skill Pilot 安装命令，桌面入口会记住这些工具位置。Skill Pilot 更新飞书时将新版放在当前用户的 `~/.local` 中并优先使用；更新前备份，可撤销。

## 分享配置与团队技能商店

- **文件分享给其他用户**：导出与导入方法见 [分享技能配置](docs/sharing-config.md)。导出文件包含技能中文名、一句话说明、分组、来源和分配关系，不包含技能正文和账号密钥；自制或已本地修改的技能会列为待补齐。
- **团队技能商店**：管理员在局域网电脑或 NAS 上运行一份团队分享站（支持 `--open` 开放加入或凭口令加入），同事用自己电脑上的看板连接，在「团队」页浏览、上架和安装技能。点「安装技能」加入安装队列，前置依赖会一并安装，页面刷新后队列仍保留；失败可重试，安装完成后到「技能」页分配给 Agent，也可在操作记录撤销。安装过的技能可打星级、写评价，自己上架的不能评价。

上架会尽量带上技能文件；疑似包含密钥、凭证的文件会被拦下，上架前可核对实际上传内容。安装优先从分享站下载，早期没有文件的上架记录仍从原来源下载；飞书官方技能仍走官方安装方式。分享站只接收主动上架的内容，不读取本机技能库或账号设置，也不安装或执行上传的技能程序。

团队分享站只适合可信局域网。开放加入时，知道地址的人都能加入并查看商店；直接使用 HTTP 连接会明文传输口令、技能文件和评价。部署、加密访问与完整用法见 [团队分享站](docs/team-hub.md)。

## 更新程序

打开看板时会自动检查一次；有新版时，技能页左栏会出现「Skill Pilot 发现新版本」提醒，**设置 → 版本** 里也会直接出现「一键升级」，不用再先点「检查更新」。

在看板打开 **设置 → 版本**：

1. 想立刻再查一次时，点「检查更新」。看板从官方 GitHub 项目准备并检查新版。
2. 有新版时点「一键升级」。当前正在执行的操作会先完成，桌面启动入口和命令行入口一起更新。
3. 出现「刷新生效」后点击它，或直接刷新浏览器，继续在原地址使用。

源码和 ZIP 安装的用户都可使用，不需要再找 Agent 操作。启动检查和手动检查时联网；技能、分配、账号设置和密钥保留在用户自己的目录。下载或新版检查失败时继续使用原版；安装途中失败会自动恢复。程序文件有本地改动，或新版与其他文件重名时，会保留现有文件并说明原因。

### 手动更新与旧版过渡

- **旧版首次接入自助更新**：先获取包含看板自助更新的新版文件，在项目文件夹运行一次安装命令（macOS 运行 `sh scripts/build-app.sh`，Windows 运行 `python -X utf8 -B scripts/install.py`），再刷新看板。不支持刷新切换的更早版本，需要正常关闭全部看板页面后重开一次。曾通过 ZIP 安装首版一键升级功能、检查时反复提示同一新版的用户，也请按手动更新步骤获取修复版并运行一次安装命令重建程序文件清单。之后即可直接在看板升级。
- **手动更新**：通过源码安装的用户，在原项目文件夹运行 `git pull --ff-only` 获取新版，再按所在平台重新运行安装命令，刷新浏览器即可生效。使用源码 ZIP 的用户，将新版解压到新的项目文件夹，在新位置运行安装命令，正常关闭全部旧看板页面后重新打开。项目文件夹移动后，也需在新位置重新运行安装命令。若新版提高 Python 等运行要求且当前电脑尚未满足，看板会保留原版并提示查看安装要求。
- **更新日志**：检查或下载新版时，连接暂时中断或超时会自动重试一次；权限不足和安全连接验证失败会直接说明原因。失败详情保存在当前用户的 `~/.skill-pilot/logs/program-update.jsonl`，包含时间、失败步骤、退出状态和经过清理的错误输出；主目录外路径自动隐藏。打开看板时的自动检查失败也会记录，账号设置不参与记录，只读模式不写日志。

## 数据放在哪

- **技能正本**：`~/.skill-pilot/store/<技能名>/`。各 Agent 技能目录里只是指向它的链接，改技能直接改正本。
- **登记表、基准、操作记录、备份及显示设置**：当前用户 `~/.skill-pilot/` 下的 `registry.json`、`bases/`、`logs/`、`backups/`、`labels.json`、`tags.json`（用户个人标签，与 AI 整理分开保存）。其他技能文件夹记在同一目录的 `extra-sources.json`。AI 服务的 API 密钥和团队分享口令分别保存在自己电脑的 `settings.json` 与 `team.json` 中，不随项目或分享配置导出。
- **操作备份自动清理**：每次改动成功后，自动只保留最近 10 次还能撤销的操作备份；一次「全部更新」整批算一次，整批一起保留、一起清理。已经撤销的操作和撤销本身不再保留备份，更早的操作不能再撤销，完整操作记录仍可导出。升级后第一次改动会按同样规则清理旧备份，只读预览不清理。
- **整理前备份永久保留**：首次整理前（包括还原后重新整理前）的备份一直保留，「设置 → 诊断与备份 → 整理与还原」和 `backups` 命令只列出这类备份，可随时还原到整理前。操作失败且自动恢复也失败的备份一直保留；收编时挪开的原件也原样保留。
- **管理规则（给所有 Agent 看）**：[AGENTS.md](AGENTS.md)。

## 开发

先读 [AGENTS.md](AGENTS.md) 和 [docs/STATUS.md](docs/STATUS.md)。需求与决策历史见 [PLAN.md](PLAN.md)，界面与文案规范见 [DESIGN.md](DESIGN.md)。看板首页的动效使用本地随附的 GSAP，文件和许可说明在 [skill_pilot/web/static/vendor/](skill_pilot/web/static/vendor/README.md)。

开发最高准则是 [通用化与可复现](AGENTS.md#最高准则通用化与可复现)。测试只在系统临时目录中的模拟用户环境运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -q
node --check skill_pilot/web/static/app.js
SKILL_PILOT_READ_ONLY=1 python3 -m skill_pilot status
sh scripts/build-app.sh   # macOS 重新生成启动器和命令行入口（勿在副本中运行）
```
